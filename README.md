# AI Steganography Web Service

A web application for hiding secret information within digital images generated by Stable Diffusion. Developed for a bachelor's thesis.

## Features
- **Container Generation:** Uses Stable Diffusion (via Hugging Face API) to create high-quality, unique images based on user prompts.
- **Robust Steganography:** Implements Discrete Cosine Transform (DCT) based embedding, making the hidden information robust against standard JPEG compression.
- **Modern UI:** Responsive React frontend with a focus on ease of use.

## Project Structure
- `/backend`: FastAPI application and steganography core.
- `/frontend`: React (Vite + TypeScript) application.

## Getting Started

### Backend Setup
1. Navigate to the backend directory:
   ```bash
   cd backend
   ```
2. Create a virtual environment and activate it:
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Set your Hugging Face API key in `.env`:
   - Create a free account at [huggingface.co](https://huggingface.co/).
   - Generate an API token in your account settings.
   - Edit `backend/.env` and replace `your_hugging_face_api_key_here` with your token.
5. Start the backend server:
   ```bash
   uvicorn app.main:app --reload
   ```

### Frontend Setup
1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Usage
1. Open the frontend in your browser (usually `http://localhost:5173`).
2. **Hide Info:**
   - Enter a prompt for Stable Diffusion.
   - Enter your secret message.
   - Click "Process Image".
   - Download the resulting PNG.
3. **Extract Info:**
   - Switch to the "Extract Info" tab.
   - Upload the encoded image.
   - Click "Extract Hidden Text".
